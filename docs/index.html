Design contract and honest limits

Problem

Claude Code is a tool loop, not a chat box. Students on a provider plan cannot pay for separate API keys, and a single model reviewing its own diff misses its own blind spots.

Mechanism

claude-oauth launches the real Claude binary behind 127.0.0.1/v1/messages. Unlike plain routers, Opus and Claude models can orchestrate Workflow scripts, subagents, and <alias>-delege workers across 7 lanes.

Verification

Two-arm native-separation probe (2026-09-08) checks clean native execution and synthetic 127.0.0.1:9 refusal. Gates ship with negative controls and mutation-verified tests.

Limit

v2.0.3 ready on Windows (B05 repaired). No turnkey installer yet; macOS is refused in src/runtime/claude-shadow.ts; 3 open findings (N07, N08, N09) remain tracked below.

One Claude Code harness. Seven upstream lanes.

Permissions, Skills, hooks, and MCP servers remain inside the parent Claude Code binary; only the /v1/messages upstream shifts.

Technical questions

Does installing claude-oauth patch or proxy my native claude command?

No. Native claude continues talking directly to api.anthropic.com. Nothing intercepts Anthropic endpoints, and scripts/native-separation-probe.mjs verifies both clean native execution and synthetic loopback rejection.

Who is this repository built for?

Students and researchers who hold a Google, xAI, or ChatGPT plan and want to learn the Claude Code tool loop with zero separate API bill, and engineers who run cross-vendor code review inside one session.

Why does the OpenAI API lane refuse OPENAI_API_KEY in the shell environment?

OPENAI_API_KEY in the launcher shell acts as an implicit API-key selector. The router refuses startup or refresh when it is set in the shell and reads the key exclusively from OPENAI_API_KEY_FILE inside the router process.

What happens to MCP data when switching /model to an API-key lane?

On Alibaba Token Plan, Z.AI, and OpenAI API lanes, mcp__* tools are never advertised, and prior mcp__* calls and results in conversation history are replaced by scrubbed text blocks carrying neither inputs nor outputs.

Why was the gemini-pro launch alias removed on 2026-11-15?

gemini-3.1-pro-high left the upstream agy models catalogue. Aliases are never silently repointed to a different model; --model gemini, argon, carbon, and hydrogen remain active.

Why choose Apache License 2.0 over MIT?

Apache-2.0 provides an explicit patent grant and structured NOTICE mechanics suitable for a project integrating multiple vendor CLIs and a patched MIT bridge (@bman654/clodex).
